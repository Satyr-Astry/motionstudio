宣传片是「代码画的」，不是录屏：app/promo/promo.js 导出确定性渲染 draw(g, t, w, h) 与两个录制入口。

  • 预览：浏览器打开 app/promo/index.html（需由本机静态服务托管，路径 /promo/index.html）
  • 录制：在应用页面里 const P = await import('./promo/promo.js'); await P.preload(); const r = await P.record({fps:30})， 再把 r.bytes 落到 docs/promo/motionstudio-promo.webm
  • 注意：应用窗口必须可见（document.hidden === false）。窗口被遮挡/最小化时 Chromium 会节流 rAF 与合帧， MediaRecorder 录出来是静止画面。另一种 encodeWebM() 用 WebCodecs 逐帧编码（与可见性无关）， 但自写的 WebM 封装没有 Cues，拖动进度条同样会回到开头。
