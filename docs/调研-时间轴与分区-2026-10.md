## 问题1 Adobe After Effects：transport / 合成设置 / 关键帧操作

- 面板分工（二手）：Project 存合成与导入素材；Composition 是画布（可切透明网格）；Timeline 管时间与图层。三者可拖拽重排，关掉后面板从 `Window` 菜单找回，布局可存为自定义工作区。
- **未验证**：transport（播放控件）在时间轴面板的具体位置——Adobe 正文不可读，二手课程稿只描述「用 Playhead 控制时间」，没写控件落在哪一栏。
- **未验证**：改已有合成时长/帧率的菜单路径。可确认的只有新建合成时在 Composition Settings 里设 preset（如 HDTV 1080 24 = 1920×1080）、像素比、帧率、时长。
- 关键帧入口：每个变换属性左侧的**小秒表**（stopwatch）一点即建首帧；`P` 位置、`R` 旋转、`S` 缩放、`T` 不透明度 单独调出属性。
- 缓动：选中关键帧按 **F9** 做平滑插值（Easy Ease）——二手来源明确写了 F9 的效果，但 Adobe 原文未取回。
- 层操作：`Ctrl+D` 复制层、`Ctrl+Shift+D` 在播放头处切开层；拖动层条改时间与叠放顺序；`Ctrl+M` 加入渲染队列，work area bar 圈定导出区间。
- **未验证**：关键帧多选方式、拖动关键帧改时间、跳到上/下一个关键帧的默认键——均无可用来源。

## 问题2 Aseprite：时间轴工具条与播放控制

- 时间轴是「行 = 图层、列 = 帧」的矩阵，贴在窗口底部；`Tab` 或 `View > Timeline` 显隐，新建帧/图层时自动出现（`Edit > Options > Timeline > Show timeline automatically` 可关闭自动弹出）。
- 时间轴上的 **Configure Timeline**（齿轮）按钮是配置入口，弹层内含 Onion Skinning 与「First frame as 0」两项——洋葱皮设置被收进时间轴的配置弹层，而不是画布旁独立面板。
- 播放：时间轴上的 **Play** 按钮，或 `Enter`；按当前帧率推进。
- 洋葱皮：`F3`，或时间轴上那个小洋葱图标（与 Configure Timeline 同处时间轴按钮带）。
- 帧时长：`Frame > Frame Properties`（快捷键 `P`）改单帧；框选多帧后右键 `Properties` 批量改。
- **未验证**：工具条按钮的完整清单与从左到右顺序——timeline / animation / frame-duration 三篇官方文档都只讲功能，未给按钮排布。

## 问题3 Krita 动画时间轴：图层与帧如何分栏

- 面板左右分栏：左侧是**图层列表**（每行带隐藏 / 锁定 / **绘图纸外观**开关，还有图钉把图层固定在顶部、避免随滚动跑掉），右侧是**帧表**（行 = 动画图层，列 = 帧）。
- 顶部工具区分两簇：左簇＝上一帧 / 停止 / 播放暂停 / 下一帧 ＋ 帧编号数值框 ＋ 预览设置（跳帧、速度）＋ 增删帧按钮；右簇＝界面元素开关、**洋葱皮**开关、动画选项菜单（动画起止帧、每秒帧数、**自动关键帧**模式）。
- 关键帧 = **实心帧格**；空白关键帧 = **空心帧格**；当前活动关键帧 = 带**斜纹**；选中帧 = 橙色高亮。
- **hold / 定格帧**：关键帧之后不再画格子，而是拉**一条有颜色的直线**延伸到下一关键帧——一眼能区分「有内容的关键帧」和「延续」。
- 拖动语义（三档区分）：直接拖 = 移动；`Ctrl` + 拖 = 复制出副本；`Alt` + 拖 = 克隆帧；`Shift` + 拖 = 连同其后所有帧一起移动。

来源：
- [Krita 手册：动画时间轴（中文）](https://docs.krita.org/zh_CN/reference_manual/dockers/animation_timeline.html)

## 问题4 Adobe Animate：图层列开关与关键帧图形

- 图层列表在时间轴左侧，底部状态条左端有 **Add Layer** 按钮；图层可重命名、隐藏、锁定、拖动改叠放顺序（等价菜单 `Insert > Timeline > Layer`）。
- 关键帧 = 帧格里一个**实心黑圆**；**空白关键帧 = 空心圆**（有键无内容，等同空白动画纸）；普通帧只是把时长往后延，可拖帧的右边缘做出多帧 hold。
- 帧级快捷键：`F5` 加帧、`F6` 加关键帧、`F7` 加空白关键帧；`,` / `.` 后退 / 前进一帧；`Enter` 播放，`Ctrl+Enter` 走 Test Movie 做实时预览。
- 右键帧的关键帧菜单把「帧 / 关键帧 / 空白关键帧」并列为同级操作：Insert Frame、Remove Frames、Insert Keyframe、Insert Blank Keyframe、Clear Keyframe、Convert to Keyframes、Convert to Blank Keyframes、Copy/Paste Frames、Select All Frames。
- 洋葱皮不在侧栏，而在**时间轴底部按钮带**：Centre Frame、Onion Skin、Onion Skin Outlines、Edit Multiple Frames、Modify Onion Markers；后者可选 Anchor Onion / Onion 2 / Onion 5 / Onion All，也可在时间轴上拖 End Onion Skin 括号设定范围。
- 帧率在 `Modify > Document` 的 Frame Rate 里改（非时间轴上）。
- **未验证**：图层列的「轮廓（outline）」开关具体图形与位置；以上为课程笔记（二手），非 Adobe 官方原文。

## 问题5 VS Code：五区职责与顶栏的克制

- **Activity Bar**：最左窄条，只放「切视图」的图标（Explorer / Search / Source Control…）和上下文指示（如 Git 变更数）；可右键改位置（Default / Top / Bottom / Hidden），移到上下时 Account 与 Manage 按钮右移进标题栏。
- **Side Bar**：Primary 与 Secondary 两侧，放视图内容；Secondary 永远在主 Side Bar 对侧；视图与面板可在两侧之间拖放，位置跨会话记忆。
- **Editor Group**：编辑器区可分多个 group（拖到边缘 / Split 命令），支持网格布局、组内 split、浮动窗口、锁定 group（新文件不再抢占该组）、钉住的 tab。
- **Panel**：默认在编辑器下方，装 Problems / Terminal / Output；可移到左 / 右 / 上；宽度对齐有 Center（默认，只跨编辑器区）/ Justify（整窗）/ Left / Right，Activity Bar 被视为窗口边缘。
- **Status Bar**：底部一条，放状态信息与通知铃（通知默认从右下角弹出，可改成 top-right 并把铃移进标题栏）。
- **顶栏刻意只放「窗口级」的东西**：主区域显隐按钮、最右的 Customize Layout 下拉（Full Screen / Zen Mode / Centered Layout / Layout Density / Quick Input Positions）、窗口标题；视图内容、终端、问题列表、命令入口都不进顶栏。菜单本身可整体隐藏或收进 Side Bar（`window.menuBarVisibility`: classic / visible / toggle / compact / hidden）。
- **命令面板**（`workbench.action.showCommands`，`Ctrl+Shift+P`）解决「功能太多、菜单放不下」：一个输入框即执行任意命令、打开文件、搜符号、看大纲；输入 `?` 列出可用命令。即顶栏不做功能总目录，功能可发现性交给命令面板 + 各视图右上角工具栏（多余动作折叠进 `...` More Actions）。

## 问题6 PSD 导入

- AE 入口：把 PSD 拖进 Project 面板，或在 Project 面板右键 `Import > File`。
- 带图层的 PSD 弹三选：**Footage**（拍平成单张）/ **Composition**（拆层，但每层都是画布全尺寸）/ **Composition - Retain Layer Sizes**（各层保留自身尺寸）；实操推荐第三项，前两项的等尺寸层会让选取与对齐变糊。
- 选 Retain Layer Sizes 时会多出 **Merge Layer Styles**：图层样式保留为可编辑，或合并进图层（合并后导入更省心）。
- 导入结果：Project 面板出现两项——与 PSD 同名的**合成** ＋ 装着全部拆出图层的**文件夹**；**Photoshop 的图层组变成嵌套在主动合里的次级合成**。
- 保留与约束：混合模式保留，Timeline 的「模式」列可查看/修改（列被隐藏时用时间轴底部按钮或右键列头勾 Modes）；画布外元素完整保留（Illustrator 素材则会被裁）；必须是 RGB，CMYK 只会作为拍平单图导入；导入项仍链接源 PSD，PS 保存即同步；文字层导入后是图像层，需右键 `Create > Convert to Editable Text` 才变原生文字层。
- Animate：`File > Import > Import to Stage`（直接上舞台并进库）或 `Import to Library`；支持 ai / psd / png / gif / jpg / swf，PSD 可带透明层。PSD 专用分层对话框的选项 **未验证**。
- Figma 官方导入列表里没有 PSD（只有 .sketch/.fig/.jam/.deck/.buzz/.site/.make、PNG/JPG、.pptx），只能靠社区插件或先拍平；Affinity 可直接打开 PSD，多数图层、蒙版与调整保留，但**智能对象与复杂滤镜可能不按预期导入**，继续编辑会改写原格式、丢特性，务必留原件。
- PSD 文件内落点：图层可见性、不透明度、混合模式、图层组、图层蒙版全在 **Layer and Mask Information** section（不是 Image Resources）；`LayerRecord` 携带 `blend_mode`、`opacity`（0–255）、`flags`（`LayerFlags.visible`）、`mask_data`、`name`；组用 `SectionDivider` tagged block（`BOUNDING_SECTION_DIVIDER` 起、`OPEN_FOLDER`/`CLOSED_FOLDER` 止，并记录 PS 中展开/折叠）；16/32 位文档的图层数据在 `Lr16`/`Lr32`。

## 问题7 圆角半径的通行做法

- **Windows / Fluent（唯一给出具体数值的一手规范）**分三级：**8px** 给顶层容器（窗口、flyout、dialog、MenuFlyout、TeachingTip）；**4px** 给页内常驻控件（Button、CheckBox、ComboBox、TextBox、ListView）和条状控件（ProgressBar、ScrollBar、Slider）；ToolTip 因体量小也用 4px；**0px** 给「与其它直边相交的那条直边」以及贴边相连的复合控件（如 SplitButton 两半的接缝、flyout 贴住触发控件那一侧）；窗口最大化/贴边时不圆角。
- 落地为两个全局资源：`ControlCornerRadius` 默认 **4px**，`OverlayCornerRadius` 默认 **8px**，应用级可覆盖——「常驻控件一套值、浮层一套值」是明确的双轨，不是随手取值。
- **KDE / Kirigami** 走「单一语义令牌」路线：HIG 不写像素，只规定「圆角 UI 元素统一用 `cornerRadius`」，Kirigami 自 6.2 起提供 `cornerRadius` 属性（按钮等矩形元素共用）；同时规定「窗口/页边与 frameless 容器视图之间的 padding 为 0」，基础网格 `gridUnit` 为 18px。
- **「大面板直角、只有浮层圆角」的惯例**：方向上被上面两条支撑——Fluent 把 8px 严格限定在浮层/窗口层，并把「与直边相交处」判为 0px；KDE 把边距压到 0 并用统一 token 管圆角。但**没有找到直接陈述「大面板一律直角」的一手文档**，只能说「面板内部接缝不圆角、圆角留给浮层」有规范依据。
- **未验证**：VS Code / AE / Blender / Figma 各自控件的具体圆角像素值——本轮未取到可引用的官方规范页，不能据此认定它们「没有规定」。
