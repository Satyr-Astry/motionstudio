# 帮助 / 图例收口与图标一致性审计（2026-10，P2 #23）

本文记录「帮助信息只有一个数据源」这件事怎么落地，以及图标系统在三个工作区里的一致性基线。
所有条目都对应到文件与函数，方便复查。

| 位置 | 内容 | 问题 |
| --- | --- | --- |
| 设置工作区「偏好」面板 | 帮助分组（文件/时间/关键帧/画板/视图） | 手写键位，和别处对不上 |

## 2. 现在的单一数据源

`app/editors/help.mjs` 导出四个常量，其余地方只许读、不许写：

```js
export const CONCEPT_ITEMS   // 画格 / 关键帧 / 时间通道 三个概念
export const SHORTCUT_GROUPS // 5 组 36 行：file / time / keyframe / draw / view
export const LEGEND_ITEMS    // 时间轴图例：kind 'cel' | 'kf' + icon + 名称 + 说明
export const CURVE_TIPS      // 曲线区怎么用
```

每行都是同一种形状：**图标 + 动作名 + 键位**（`{ icon, name, keys, hint? }`），分组带自己的 `icon`。
设置里的键位行、帮助面板的键位行、时间轴图例全部由这份数据渲染：

- `app/editors/prop-prefs.mjs`：`makeHelpRow` / `makeLegendRow` 渲染到 6 个面板（`pref-help-file` … `pref-help-legend`）。
- `app/editors/help.mjs` 的 `mount()`：帮助面板用 `row(iconName, keyText, descText)` 画出同一份表。
- `app/editors/timeline-paint.mjs`：`buildCard()` 遍历 `LEGEND_ITEMS`，原来的本地 `LEGEND_ROWS` 已删除。

漂移由测试兜住：`tests/icons.test.mjs` 里「图例同源：时间轴浮层与设置都只读 help.mjs 那一份」会断言
`timeline-paint.mjs` 不含 `const LEGEND_ROWS =`、`prop-prefs.mjs` 不含 `const SHORTCUT_GROUPS =`。

## 3. 段条字号（A 段）

`app/editors/timeline-geo.mjs` 的 `FPS_H` 从 9 抬到 **12**：10px 的 `12fps` 在此之前只靠 `overflow:hidden`
勉强不裁，行高与字号只差 1px。真机读数（1680 与 1280 一致）：段条 `807..819`、刻度尺 `825..835`，
间隙 6px；段条 `scrollWidth === clientWidth`（1680 下 335=335，1280 下 610=610），没有残字。
窄段阈值仍是 `< 42`（10px 下「12fps」约需 40px）。

## 4. 曲线预设（C 段）

保持「图标 + 单字」（`线 入 出 双 冲 自`），`.curve-preset` 固定 38px 不动 —— 这是排版红利，
改成两字会直接吃掉曲线编辑器的横向空间。六项的 `title` 写成全称：
线性插值（匀速）/ 进入（缓入）/ 退出（缓出）/ 双向（缓入缓出）/ 回弹（超调）/ 自由。

## 5. 图标一致性审计（E 段）

- **尺寸档**：`icons.css` 里只有三档 —— 默认 16px（`--icon`）、`size:'sm'` 14px、`size:'lg'` 20px。
  实测用法：16px 12 处、14px 8 处、**20px 0 处**（定义了但没人用，见遗留第 3 条）。
  同一行里不会混档：面板按钮 16px，行内小徽标（菱形、效果胶囊、曲线预设）14px。
- **`currentColor`**：全部 51 个图标都用 `stroke="currentColor"`，没有任何硬编码颜色；
  唯一的颜色来源是宿主的 `color`（`.ms-icon` 不设 `color`）。
- **emoji / Unicode 混入**：审计脚本在全工作区扫「文字 ≤2 字的按钮」，
  只剩 `button.cv-hud-btn«−»` 与 `«＋»`（画布 HUD 缩放），见遗留第 1 条。
- **同义别名（已修）**：帮助表原来用 `pen / fill / picker / hand`，而工具条用的是
  `brush / bucket / eyedropper / move` —— 同一动作两个图标名。现统一为工具条那套，
  并删掉 `icons.mjs` 里 4 个零引用的别名条目（55 → 51）。新增 `search`（命令面板用）。
- **疑似死条目**：`eye-off`（`layers.mjs:598` 的 `wantEye` 动态引用）与 `pause`
  （`timeline-paint.mjs` 的 `icon(playing ? 'pause' : 'play')`）都是动态引用，不是死条目。

## 9. `?` 浮层的数据源收口（task-11，第二轮）

**之前**：`app/shell/app.mjs` 里是
`createShortcutsOverlay({ groups: groupsFromCommands(buildCommands()).concat([{ title: '全局', items: [...] }]) })`
—— 键位来自 `COMMANDS` 的 `keys/group/title`，再手补一组「全局」5 条。这就是第二份键位数据。

**现在**：`app/editors/help.mjs` 新增

```js
export function overlayGroups(groups = SHORTCUT_GROUPS) // → { groups: [{ title, items: [{ keys, title, hint }] }] }
```

`app.mjs` 只剩一行 `shortcuts = createShortcutsOverlay({ groups: overlayGroups() });`。
`COMMANDS` 从此只管「命令 → 键位」（命令面板条目右侧的快捷键提示），不再往浮层灌描述文案。
原手补的「全局」组已并入 help 表：`Ctrl+Shift+P` 与 `↑ / ↓` 进 `view`，`Shift+拖` 在 `keyframe`，
`Ctrl+滚轮` 在 `time`，`Esc` 在 `view`。`shortcuts-overlay.mjs` 未改动 —— 浮层 DOM 结构与样式不变。
