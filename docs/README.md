## 新增文档的规矩

1. 账本类命名 `主题-YYYY-MM.md`，并在主账本 [修复列表-v8.md](修复列表-v8.md) 里加一行指向它。
2. 每条结论必须带证据：代码给 `文件:行号`，界面给真机读数或截图名；查不实的写「未确证」。
3. 不要在这里放一次性调试脚本（`.gitignore` 已排除 `patch-*` / `probe-*` / `dbg*`）。
