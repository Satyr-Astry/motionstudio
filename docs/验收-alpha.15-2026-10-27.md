# 验收 · v0.5.0-alpha.15（时间基准与效果身份）

本轮修的三件事里有**两件是数据层的，屏幕上不点特定动作看不出来**。所以这份清单按「点哪里 → 看什么 → 不符说明什么」写，每条都给可指认的判据。

前提：在项目根 `npm start`（或直接跑 `node_modules\electron\dist\electron.exe .`）。不用重装、不用清缓存，`localStorage` 里的旧项目会自动走老档兼容路径。

---

## A. 时间基准：在时间子树里打帧应该落在局部时间上（本轮主修）

这条是**唯一能被肉眼抓到错位**的，也是最值得先验的。

准备：新建一个对象，在 0s 把「位置 X」拖到 0、在 1s 拖到 200（让它有个一眼能看出的位移）。

1. 在**叠放列表**点该行右侧的 ⏱ 徽章 → 浮层里「倍率」填 `2` → 关闭浮层。此时对象名后面会出现 `×2` 标记。
2. 把播放头拖到**全局 1.0 秒**。该对象的局部时间此刻是 **2.0 秒**。
3. 打开曲线面板，勾上 `X` 通道。
4. 在属性面板把「位置 X」滑杆拖到 300 左右（拖一下就是打帧）。

期望（三条同时成立）：

- 曲线里新出现的圆点横坐标在 **2.0s** 附近，不是 1.0s。
- **松手瞬间画面位置就变**。旧版要点播放、或把播放头拖走才变——因为帧打在 1.0s、求值却按局部 2.0s 去读，读不到。
- 曲线提示条末尾出现「· 对象时间」。

不符的话：`app/shell/commands.mjs` 的 `localTimeOfLayer` / `writeKeyAt` 换算没生效，回滚点就是这两处。

## B. 效果身份：删中间一条不应该串到别人身上（本轮新增）

1. 选一个对象，属性面板「效果」组依次点 **模糊**、**外发光**、**投影** 三个图标（每个图标是「给当前对象加一个 X」）。
2. 把「外发光」的强度拖到 10，点它右边的 ◆（当前时间打帧，胶囊上会出现「已动画」小点）。
3. 点「外发光」胶囊上的 × 删除。

期望：剩下两条（模糊、投影）的参数、轨道、表现原封不动；播放时外发光消失、另两个照旧。

旧版的风险在这里：面板删除按钮闭包里记的是构建 DOM 那一次的下标，重绘前点下去会删错条目；签名只认 `type` 序列，同类型两条互换位置识别不出来。

## C. 存档往返：保存再打开，效果与纹理都该在（alpha.14 的修复，顺带回归）

1. 给对象加效果 + 打几帧 → 保存项目 → 关闭项目 → 重新打开。

期望：效果列表、参数、轨道全在。旧版是**整条 `effects` 字段根本没进白名单**，保存即消失。

2. 找一个有两张以上纹理的对象（时间轴上多个纹理点），把第二个纹理点拖到另一个时刻 → 保存 → 重开。

期望：纹理还在它被拖到的时刻；删掉纹理点再保存重开，**已删的不复活**。旧版写的是 `cels` 投影，投影没跟着重算，就会出现错位与复活。

## D. 清理的副作用（改了 110 行删码，回归看一眼）

- 叠放列表是**扁平**的（不缩进）；父子面板按层级缩进，每级 12px、最多显示到 6 级。
- 父子面板里 `Shift` 连选：选中的是**屏幕上自上而下那一段连续行**，不是内部数组的一段。
- 属性面板拖动、时间轴拖动、⏱ 浮层六件都不受影响（`ctx.subtreeCount` / `ctx.layerDepth` 两个零调用包装已删，它们没有任何界面入口）。
