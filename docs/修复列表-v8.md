# MotionStudio v8 修复列表（按 m10774 需求逐条拆解）

> 这是一份「问题 → 原因 → 处置」的账本，不是愿望清单。每条都标了证据来源：
> **代码** = 在哪个文件哪一行、**真机** = CDP 探针读数、**测试** = 哪个用例。
> 配套调研见 [`调研-时间轴与分区-2026-10.md`](./调研-时间轴与分区-2026-10.md)。

## 0. 一句话结论

界面问题的根不是「皮肤不好看」，而是**职责错位**：窗口级动作（播放/时长）长在了顶栏，
内容级动作（画格/关键帧）长在了属性面板，而真正的时间轴只剩「画」这一件事没做全。
v8 的处置顺序就是把这四件事各归其位：顶栏 = 文件与工作区，时间轴 = 时间，对象面板 = 内容层级，属性 = 选中对象的参数。

## 3. 市面软件怎么做的（调研摘要）

完整引用见 [`调研-时间轴与分区-2026-10.md`](./调研-时间轴与分区-2026-10.md)。

- **位置即语义**：AE / Aseprite / Animate 的播放控制都在时间轴侧，不在窗口顶栏；VS Code 顶栏只放主区域显隐与布局定制，其余动作折叠进各视图右上角 `...`。
- **关键帧的视觉语法**：Animate 用实心圆=关键帧、空心圆=空白关键帧；Krita 用实心/空心/斜纹/彩线区分关键帧、空白关键帧、活动关键帧与 hold —— 我们现在的方块（画格）/菱形（关键帧）已经对齐这套语法，需要补的是**多选与框选**。
- **时长与帧率**：Aseprite 走 `Frame > Frame Properties`，Animate 走 `Modify > Document`；两者都是「显式入口 + 明确数值」，而不是靠「时长倍数」间接推算 —— 这正是我们把 `tline-total` 做成可输入 + 刻度尺右端手柄的依据。
- **导入 PSD**：AE 提供 Footage / Composition / Composition-Retain Layer Sizes 三选，组会变成二级合成；Figma 官方不支持 PSD，Affinity 保留多数图层但可能丢智能对象 —— 我们的第一步是「每图层一个对象」，组层级留作后续。
- **圆角**：Fluent 的三级是 8/4/0（浮层/控件/与直边相交处），KDE 用统一 `cornerRadius` 令牌且容器 padding 不收 —— 「大面板直角、浮层圆角」有规范依据。

## 4. 建议新增（自主分析）

1. **对象组（父子可视化）**：`parentId` 已存在但对象面板只在拖拽时体现，缺缩进树与折叠三角。
2. **吸附开关（磁铁）**：时间轴工具条加一个磁铁按钮，控制「关键帧/画格/播放头」是否吸附到帧格或 0.1 s 网格；现在是按住 Shift 才吸附，不够直观。
3. **播放时的降采样预览**：播放期跳过洋葱皮与效果滤镜，暂停后补一帧精确渲染（AE 的「快速预览」思路）。
4. **导出 GIF / WebM**：现在只有 PNG 序列与精灵图；GIF 可用纯 JS 编码，WebM 走 `MediaRecorder`（Electron 里可用）。
5. **命令面板（`Ctrl+Shift+P`）**：VS Code 式可发现性入口，把「加画格/打关键帧/导出/切换工作区」全列进去，解决「功能藏得深」。
6. **快捷键表浮层（`?`）**：与命令面板共用数据源，一处定义两处呈现。
7. **PSD 组 → 父子对象**：`lsct` 组信息已解析，接上后组即父对象，子图层保留相对坐标。
