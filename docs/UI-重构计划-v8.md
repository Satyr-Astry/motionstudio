# UI 重构计划（v8 第三阶段：控件瘦身 + 画板吸收 Klecks）

> 目标用户诉求（m13630）：全方位优化 UI 布局、删冗余控件、合并同类、简化操作、统一美观、借鉴先进 UI；
> 画笔/调色等工具既然已经并入画板，就把 Klecks 的关键功能尽量搬进画板。**先计划，再派活，再验收。**

## 0. 一句话结论

绘图区现在有**三套重复的画笔入口**（顶栏无、左列「工具」面板一套、画板自带一套），调色又分散在「调色」面板与画板之外；
编排区则是「属性面板 6 组 + 时间轴 13 键」平铺，缺少主次。重构方向：**每个工作区只留一套操作面板，控件按「常用在前、进阶可折叠」排列，视觉按统一令牌收口**。

## 3. 画板控件设计（Klecks 移植清单）

工具条（一行，`.bd-bar`）：
`[笔刷预设▾][当前色块][大小 ◯─][不透明度─][取色器][镜像▾][撤销↶ 重做↷]  …  [‹ › ＋纹理 独特化 适配]`

- **笔刷预设**：下拉或行内 chip（像素/圆/软/铅/晕染/散点/橡皮），带图标化缩写；`[` `]` 调大小、`1..7` 直选。
- **当前色块**：点击展开色板（最近 6 色 + 前景/背景交换）；画布上按住 `Alt` = 吸管。
- **笔刷设置弹层**（`⋯`）：硬度 / 间距 / 抖动 / 流量四个滑杆 + 「恢复笔刷默认」；值按 `brushId` 记忆在 `localStorage['ms.brush.<id>']`。
- **镜像**：无 / 左右 / 上下 / 四向；绘制时对 stamp 位置镜像（纯前端，不改数据）。
- **撤销/重做**：画板内直接给按钮（引擎 history 已有 `pushCommand`）。
- **笔刷游标**：画布上画一个圆圈预览（随 zoom 变化），`pointerleave` 隐藏。
- 保留：滚轮缩放、空格/中键平移、0 键适配、纹理切换。

## 4. 调色盘设计

- 画板内的「当前色块」= 主入口：点击弹出色板（最近色 + 常见色 + HSV 简版）。
- 左列「调色」面板保留为**进阶**：HSV 方块 + 明度条 + hex + 最近 12 色；在绘图区可见但不再承担「唯一入口」。
- 统一：两处都走 `ctx.setColor()`，颜色来源单一（`engine.color()`）。

## 5. 实施批次与验收标准

| 批次 | 内容 | 验收（真机 CDP + 单测） |
| --- | --- | --- |
