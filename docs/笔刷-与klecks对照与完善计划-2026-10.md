# 笔刷：与 Klecks 的逐项对照与完善计划

- 日期：2026-10
- 对象：画板（`app/editors/board.mjs`）的 7 支笔刷 vs Klecks（`E:\dev\klecks`，MIT）
- 性质：**只调研，不改代码**。所有引用给文件:行号；查不到的写「未确证」。

## 0. 一句话结论

我们和 Klecks 差的不在「少几支笔刷」，而在**三件底层能力**：压感没接进**画板**的落笔路径（`engine.mjs`
那条舞台画布路径已接）、笔尖只有「径向渐变圆」一种形状、混色类笔刷的算法量级不同（Klecks 是逐像素/分块运算，我们是位图搬运）。
笔刷数量上差 3 支（Blend / Sketchy / Chemy），但先把前两件补上，7 支的手感差异比多 3 支笔刷更大。

## 0.5 用户最先注意到的五个现象，各对应文档哪一条

这张表是为了让「复刻不完善」这个直觉能直接落到下面的具体条目上（每一条的差异都是可测的，不是体感）：

| 现象 | 根因 | 对应条目 |
| --- | --- | --- |
| 轻轻画和用力画一样粗 | 画板没读 `PointerEvent.pressure`；`engine.mjs` 已读（见 §1 压感行） | §3 #1 |
| 半透明笔画两三点就变实色、晕染越拖越糊 | 间距口径换算后我们叠的点是它的 3.5 倍（软笔 5.3、散点 8.5） | §3 #7、§2.2 |
| 铅笔没有「纸纹/粉笔」质感 | 笔尖只有径向渐变圆与实心圆两种来源，没有 alpha 纹理 | §3 #4、§2.3 |
| 45° 斜线有断点、边缘有毛刺 | 像素笔没用 Bresenham，靠 `fillRect` + 间距插值 | §2.4 |
| 晕染是把颜色「搬」过去，不是抹开 | 位图搬运式 smudge，Klecks 是逐像素 lerp + dither | §3 #6、§2.5 |

| 单点绘制 | `app/editors/board.mjs:720-766` | `stamp()`：`source-over` / 橡皮 `destination-out`（`:728`）；scatter（`:729-741`）；smudge（`:742-756`）；普通（`:757-764`） |
| 每点透明度 | `app/editors/board.mjs:697-700` | `paintAlpha() = opacity × flow`，**常量，与压感无关** |
| 稳定器 | `app/paint/stabilizer.mjs` | 单级 EMA（alpha 衰减表 + MIN_STEP），松手追平（`board.mjs:840-845`） |

**结论先行**：压感这条链路在 `engine.mjs` 里是**完整可用**的（选压 → 压感曲线 → 插值点携带压力 → `stampAt` 收压力），
但那是舞台画布；画板 `board.mjs` 的 `stamp()` 只做一次 `drawImage(tip)`，形状与不透明度都封在 `tip` 位图里 —— 这就是画板笔刷手感的全部。

## 2. 逐笔刷对照表

Klecks 的 7 支注册在 `brushes/brushes.ts:9-17`。笔尖形状常量在 `brushes/pen-brush.ts:15-18`：
`ALPHA_CIRCLE=0 / ALPHA_CHALK=1 / ALPHA_CAL=2 / ALPHA_SQUARE=3`。

### 2.1 圆笔（我们 `round`）

| | |
| --- | --- |
| Klecks 怎么做 | `PenBrush`（`pen-brush.ts:25`）。默认 `settingSize=2`、`settingSpacing=0.8489`（`:32-33`）；落点用**矢量** `arc(x,y,size)` 填充（`:187-191`），不经过位图；`settingHasSizePressure=true`（`:31`）→ `size = max(0.1, pressure * settingSize)`（`:231-233`） |
| 我们怎么做 | `brush.mjs:39`：`hardness .85 / spacing .12`；`board.mjs:720-766` 位图 `drawImage` 逐点 |
| 差在哪 | ① 无压感变粗细（最直观的差距）② 位图笔尖在 `size` 很小时会糊（Klecks 矢量圆不受影响）③ **间距密度差 3.5 倍**：Klecks 的 `size` 是**半径**（`arc(x,y,size)`，`pen-brush.ts:189`），间距 = `R × 0.8489`；我们的 `spacing` 是**直径倍数**（`brush.mjs:33` 注释），间距 = `2R × 0.12 = R × 0.24` → 同一笔画我们叠的点约为它的 3.5 倍，半透明时更容易到顶 |
| 等级 | **关键缺**（压感） |

### 2.2 软笔（我们 `soft`）

| | |
| --- | --- |
| Klecks 怎么做 | 同一 `PenBrush`，靠 `settingOpacity` 压低；`calcOpacity()` = `settingOpacity × (hasOpacityPressure ? pressure² : 1)`（`pen-brush.ts:120-122`）—— **压感映射透明度用平方曲线** |
| 我们怎么做 | `brush.mjs:40`：`hardness .08 / flow .32`；软边来自 `createRadialGradient` 的两段 stop（`:176-183`，`h*0.95` 处开始衰减） |
| 差在哪 | ① Klecks 的「软」是**低不透明 + 圆笔**，边缘仍是硬边圆；我们的「软」是**渐变边缘**——两者不是一回事 ② 我们无法让软笔随压感变透明 |
| 等级 | 细节差（理念不同，我们的软边其实更好用；但缺压感） |

### 2.3 铅笔（我们 `pencil`）

| | |
| --- | --- |
| Klecks 怎么做 | 对应 `ALPHA_CHALK` 分支：`drawImage(mipmap, ...)` 用**粉笔纹理**（`pen-brush.ts:202-219`），且每个 dot 按 `(x+y)*53123 % 2π` **随机旋转**（`:213-215`）；纹理本体是 perlin 噪声 + 圆形 falloff（`alphas/brush-alphas.ts:6-46`） |
| 我们怎么做 | `brush.mjs:41`：`hardness .55 / jitter .22 / flow .82`；jitter 在 `board.mjs:760-762` 做 ±`half` 的均匀随机偏移 |
| 差在哪 | ① **笔尖纹理完全缺失**（这是铅笔质感的主要来源）② 我们的 jitter 是「位置抖」，Klecks 是「纹理旋转抖」——后者更像纸纹 ③ Klecks 有 128/64/32 三档 mipmap（`pen-brush.ts:206-211`），我们只有一张位图 |
| 等级 | **关键缺**（纹理） |

### 2.4 像素笔（我们 `pixel`）

| | |
| --- | --- |
| Klecks 怎么做 | `PixelBrush`（`pixel-brush.ts:28`）。`settingSpacing=0.9`、`settingPattern`（图案：solid 等，`pixel-brush-patterns.ts`）、`settingTip='round'`（`:37-38`）；用 **Bresenham** `plotLine()` 精确画像素线（`:302`）；圆盘落点用 `PixelDiscUnion`（`:74`）；`drawStroke` 走 `source-atop` 锁 alpha（`:134`） |
| 我们怎么做 | `brush.mjs:38`：`hardness 1 / spacing 1 / antialias false / pixelGrid true`；`makeTip` 用 `fillRect`（`:161-165`），落点由 `snapPixel`（`stroke.mjs:96`）对齐整格 |
| 差在哪 | ① 我们**没有 Bresenham**，靠间距插值 + 方块，斜线会出现「跳格/缺角」② 无图案（我们只有纯色）③ 无 `round/square` 笔尖形状切换 ④ 无锁 alpha |
| 等级 | 细节差 → 斜线质量可算**关键缺** |

### 2.5 晕染（我们 `smudge`）

| | |
| --- | --- |
| Klecks 怎么做 | `SmudgeBrush`（`smudge-brush.ts`）。`settingSize=35`、`settingSpacing=0.20446882736951905`、`settingOpacity=0.8`（`:278-280`）；核心是**逐像素搬运**：取源像素 `a` 与目标像素 `b`，`data[bi] = mix(a, b, fac2) + randArr[randI]`（`:197-205`）—— 混色时还加**随机 dither 抖动**；alpha 单独按 `fac` 混（`:211-212`）；源 alpha=0 跳过、目标 alpha=0 直接复制（`:177-185`）；`CELL_SIZE=256` 分块（`:26`），文件头有实测性能表（`:15-24`，size 100 时 0.09–1ms/次） |
| 我们怎么做 | `board.mjs:742-756`：从**纹理自身**在上一落点取 `d×d`，用 `destination-in` 套笔尖遮罩，再 `drawImage` 到当前点（`:750-754`），额外以 `alpha*0.25` 叠一次原笔尖（`:755-756`） |
| 差在哪 | ① 我们是**整块搬运 + 反复叠加**，Klecks 是**逐像素 lerp 一次**——我们的结果是「越拖越糊成一团」，Klecks 能保持色彩结构 ② 我们没有 dither 抖动，长笔会出明显的色带 ③ 我们每点两次 `drawImage`（搬运 + 笔尖），Klecks 一次遍历 |
| 等级 | **关键缺**（算法量级不同） |

### 2.6 散点（我们 `scatter`）

| | |
| --- | --- |
| Klecks 怎么做 | 没有独立散点笔刷：`SettingScatter` 是 `PenBrush` 的一个参数（`pen-brush.ts:35`、`:124-128`），每个 dot **只随机偏移 1 个位置**（`:167-173`，`sqrt(random)*scatter` 保证圆内均匀） |
| 我们怎么做 | `brush.mjs:46`：独立笔刷 `scatter: {count: 7, spread: 1.1}`；`board.mjs:729-741` 每个落点撒 **7 个点**，`globalAlpha = alpha / sqrt(n)`（`:738`） |
| 差在哪 | 语义不同：Klecks 是「一支笔的随机性」，我们是「一支专门撒点的笔」。我们的 `alpha/sqrt(n)` 是合理归一化，但**7 点 × 每 0.05 直径的间距**导致同一点被反复覆盖，`opaque` 计数会比预期高 |
| 等级 | 有意不同（保留），但缺「作为其它笔刷的可调参数」这一层 |

### 2.7 橡皮（我们 `eraser`）

| | |
| --- | --- |
| Klecks 怎么做 | `EraserBrush`（`eraser-brush.ts`）。`drawDot` 先 `destination-out`（`:54`），若锁 alpha 改 `source-atop`（`:56-57`）；有 `setTransparentBG(b)`（`:244`）——**擦到透明 vs 擦到背景色**两种模式；`settingHasSizePressure` 可开（`:236`） |
| 我们怎么做 | `brush.mjs:47`：`hardness .8 / erase: true`；`board.mjs:728` 切 `destination-out` |
| 差在哪 | ① 无「擦到背景色」模式 ② 无锁 alpha ③ 无压感变大小 |
| 等级 | 细节差 |

### 2.8 Klecks 有、我们没有的三支

## 4. 分层：改动应该落在哪

| 层 | 能做的（纯函数、Node 可测） | 不能做的 |
| --- | --- | --- |
| `app/paint/`（`brush.mjs` / `stroke.mjs` / 新模块） | 压感曲线与三条映射的**计算**、笔尖纹理生成、软边衰减函数、Bresenham 像素线、smudge/blend 的**像素运算**、平滑滤波的多 pass 数学 | 不能决定「什么时候采样」「采样到几个点」 |
| `app/editors/board.mjs`（交互层） | 从 `PointerEvent` 取 `pressure` / coalesced events、调用新纯函数、把 `stamp()` 换成新绘制路径、选区裁剪的 `clip()` 调用 | 不应内嵌笔刷算法（现在 `stamp()` 里的 scatter/smudge 就该往外挪） |
| `app/paint/engine.mjs` | 它是**舞台编辑器**的完整笔刷引擎，不是空壳：`startStroke`（`:454-476`）建房程、`extendStroke`（`:557-572`）用 `spacingPoints` 补插值点并 `stampAt(sp.x, sp.y, sp.p)`、`pressureOf`（`:399-402`）把 `PointerEvent.pressure` 过 `pressureCurve`。**压感在这里是完整可用的参考实现** | 它的落笔目标是 `activeCel()` / `docSize()` / 历史栈（依赖舞台文档与 `setDoc` 语义），画板有私有相机（`cam`）与自己的纹理写入口 → **不能直接复用，只能照抄做法**；也别为了画板去改它的 tool 分支 |

**验收读数（全部可在现有真机脚本里量）**

1. 压感：用 `PointerEvent` 伪造 `pressure=0.2 / 0.8 / 1.0` 各画一条水平线，纹理**包围盒高度**应为 `size×0.2±1 / size×0.8±1 / size±1`（当前三条完全相同）。
2. 平滑：同一条手抖轨迹（现有 `w5-trace` 那组），level 0 → 3 的**笔迹包围盒高度**从 21px 降到 ≤10px，**中心线拐点数** 3 → ≤1（现有基线 21/3 与 8/1 已由 task-6 量过，升级后不得退化）。
3. 笔尖纹理：选铅笔后在空白纹理上画一笔，`opaque 像素数 / 包围盒面积` 应落在 0.35–0.75（纯色圆笔接近 1.0）——这条读数把「有没有纹理」变成数字。
4. 锁 alpha：先画半透明圆、再开锁 alpha 画一笔，**alpha 通道总和**变化 ≤1%。

## 6. 第一周最该做的 3 条

1. **压感接进画板落笔路径**（`board.mjs:720/799` + `brush.mjs` 开关，**S**）。
   理由：整条链路 `engine.mjs` 里已经跑通了（`:399-402` 选压 → `:564` 插值点带压 → `stampAt` 收压），画板只需照抄这段并改 `stamp()` 签名 —— **已有零件没接线**，投入产出比最高，也是「笔刷像不像 Klecks」的第一观感来源。
2. **笔尖纹理（chalk / calligraphy）**（新 `tip.mjs` + `alphas` 生成器，M）。
   理由：7 支笔里「铅笔」的质感完全依赖它；而且这是**纯函数 + 可数值断言**（§5 第 3 条读数），风险最低。
3. **`spacing` 预设重标定**（`brush.mjs:37-48`，S）。
   理由：我们 `spacing .12`（**直径**倍数）换算成 Klecks 的**半径**口径是 `R × 0.24`，而 Klecks 圆笔是 `R × 0.8489` —— 同一笔画叠的点约 3.5 倍（软笔 5.3、散点 8.5）。这解释了「我们的半透明笔画很快变成实色」和「晕染越拖越糊」两个现象。改预设是 20 行以内的事，但会改变 7 支笔的既有手感，必须配真机基线重测。

**不建议第一周碰**：smudge 重写、BlendBrush、选区裁剪 —— 三件都要先有「像素级运算 + 撤销体积」的公共设施，否则会在 `board.mjs` 里再堆一层。
